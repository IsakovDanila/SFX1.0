# 📥 Как добавить свои аудиофайлы

## Быстрый способ (через интерфейс)

1. **Откройте приложение** — запустите `npm run dev` и откройте http://localhost:5173

2. **Перейдите в каталог** — нажмите на вкладку "Каталог" в шапке

3. **Нажмите кнопку "Импорт файлов"** — она находится справа от фильтров категорий (голубая кнопка с иконкой загрузки)

4. **Добавьте файлы одним из способов:**
   - **Drag & Drop** — перетащите аудиофайлы прямо в окно импорта
   - **Выбор файлов** — нажмите на область загрузки и выберите файлы через диалог

5. **Выберите категорию** — перед импортом можно выбрать категорию для новых файлов (Боевые эффекты, Шаги, Амбиент и т.д.)

6. **Дождитесь анализа** — приложение автоматически определит:
   - Длительность
   - Частоту дискретизации (sample rate)
   - Количество каналов (моно/стерео)
   - Высоту тона (низкий/средний/высокий)
   - Энергию (low/medium/high)
   - Наличие шума и реверберации

7. **Готово!** — файлы появятся в каталоге, их можно воспроизводить, искать, размечать

## Поддерживаемые форматы

- **WAV** (.wav) — рекомендуется для лучшего качества
- **MP3** (.mp3)
- **OGG** (.ogg)
- **FLAC** (.flac)
- **AIFF** (.aiff)
- **M4A** (.m4a)

## Как это работает технически

### Анализ в браузере (Web Audio API)

Все аудиофайлы анализируются прямо в браузере через **Web Audio API** — никаких данных не отправляется на сервер:

```typescript
// Пример анализа
const audioCtx = new AudioContext();
const audioBuffer = await audioCtx.decodeAudioData(arrayBuffer);

// Определяем характеристики
const duration = audioBuffer.duration;
const sampleRate = audioBuffer.sampleRate;
const channels = audioBuffer.numberOfChannels;

// Спектральный анализ
const channelData = audioBuffer.getChannelData(0);
// ... расчёт RMS, zero-crossing rate, и т.д.
```

### Хранение файлов

- **Демо-файлы** — генерируются синтетически (без реального аудио)
- **Импортированные файлы** — хранятся как `objectURL` в памяти браузера
- **После перезагрузки** — импортированные файлы нужно добавить заново (или подключить бэкенд)

## Для полноценного семантического поиска

Если хотите использовать **CLAP embeddings** и **ChromaDB** для умного поиска по описанию:

1. **Запустите бэкенд** (папка `backend/`):
   ```bash
   cd backend
   pip install fastapi uvicorn chromadb librosa laion-clap torch numpy
   uvicorn main:app --reload --port 8000
   ```

2. **Фронтенд автоматически подключится** — в футере появится зелёный индикатор "API: подключён"

3. **Используйте поиск** — теперь можно искать по текстовому описанию через CLAP embeddings

## Примеры использования

### Добавление звуков для игры

1. Импортируйте папку с звуками шагов
2. Выберите категорию "Шаги"
3. Приложение автоматически определит характеристики
4. Перейдите в "Разметку" и добавьте теги: "дерево", "камень", "быстрый"
5. Теперь эти звуки можно найти через поиск

### Поиск похожих звуков

1. Загрузите референсный .wav файл в поиске
2. Приложение найдёт похожие звуки по звучанию
3. Оцените качество выдачи в режиме "Оценка"

## Ограничения браузерной версии

- **Нет постоянного хранения** — после перезагрузки импортированные файлы нужно добавить заново
- **Нет семантического поиска** — только базовый поиск по тегам и описаниям
- **Нет пакетной обработки** — файлы анализируются по одному

### Решение: подключить бэкенд

Бэкенд на FastAPI + ChromaDB решает все эти проблемы:
- Постоянное хранение в векторной БД
- CLAP embeddings для семантического поиска
- Пакетное сканирование директорий
- API для интеграции с другими инструментами

## FAQ

**В: Можно ли импортировать сразу всю папку?**
О: В браузерной версии — нет (браузер не позволяет читать папки). В desktop-версии (Electron) — да, через `electron/main.js`.

**В: Файлы сохраняются после перезагрузки?**
О: В браузерной версии — нет. Используйте бэкенд с ChromaDB для постоянного хранения.

**В: Какие характеристики определяются автоматически?**
О: Длительность, sample rate, каналы, высота тона, энергия, шум, реверберация. Всё через Web Audio API.

**В: Можно ли редактировать теги после импорта?**
О: Да! Перейдите в режим "Разметка" и добавляйте/удаляйте теги для каждого файла.

**В: Как найти конкретный звук?**
О: Используйте вкладку "Поиск" — опишите звук текстом или загрузите референсный .wav.
